# 💬 Full Stack Chat/DM Application

This is a **full-stack chat and direct messaging app** featuring a modern React.js frontend and a Node.js backend. It includes user authentication, persistent chat history, and real-time communication powered by the Chat.io API.

---

## 🚀 Features

- 🧑‍💻 **User Authentication**  
  Users can sign up, log in, and securely access the app.

- 💬 **Real-Time Messaging**  
  Users can chat with one another instantly using the Chat.io API.

- 💾 **Persistent Chat History**  
  Chats are saved, so users can log out and return later without losing their messages.

- 🌐 **RESTful API**  
  The Node.js backend handles authentication and chat logic using a REST server.

---

## 🛠 Tech Stack

**Frontend:**  
- React.js  
- JavaScript  
- HTML/CSS  

**Backend:**  
- Node.js  
- Express (REST server)  
- Chat.io API
